PUBG DARK - نسخه کامل‌تر نمایشی

1. فایل ZIP را Extract کنید.
2. فایل index.html را با Chrome باز کنید.
3. برای آنلاین شدن سایت، کل محتویات این پوشه باید روی هاست آپلود شود.
4. این نسخه شامل ظاهر سایت، دسته‌بندی‌ها، جستجو، محصولات نمونه و سبد خرید آزمایشی است.
5. مرحله بعدی: دیتابیس، ثبت‌نام، پنل مدیریت، پرداخت واقعی و تحویل خودکار.
